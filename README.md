✈️ TripNest – Travel Booking Platform

🔗 - https://tripnest-4-gxzg.onrender.com

TripNest is a modern full-stack travel booking platform that allows users to explore destinations, search travel packages, and book trips seamlessly.
Built with scalability, performance, and clean UI/UX in mind.

🌍 Overview

TripNest simplifies travel planning by providing:

Destination discovery

Package search & filtering

Secure booking system

User dashboard

Admin management panel

The platform focuses on speed, responsive design, and intuitive user experience.

🚀 Features
👤 User Features

User Authentication (Signup / Login / Logout)

Browse Popular Destinations

Search & Filter Travel Packages

View Detailed Trip Information

Book Trips

Booking History

Responsive Design (Mobile + Desktop)

🛠️ Admin Features

Add / Edit / Delete Travel Packages

Manage Bookings

Manage Users

Dashboard Analytics
